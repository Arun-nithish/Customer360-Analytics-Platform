# Customer360 Analytics Platform (Portfolio Project)

## Overview
End-to-end e-commerce analytics project showcasing SQL, Python, KPI reporting, EDA, RFM segmentation, cohort analysis concepts and Power BI dashboard design.

## Business Questions
1. Which regions generate the highest revenue?
2. Who are the highest-value customers?
3. Which categories drive profit?
4. How does revenue trend over time?
5. Which customers are at risk?

## Skills
Python, Pandas, NumPy, SQL, Power BI, Data Visualization, Business Analytics

## Project Structure
- Data Cleaning
- Exploratory Data Analysis
- KPI Reporting
- RFM Segmentation
- SQL Business Analysis
- Dashboard Design
